# 0.1.1 检查记录

日期：2026-11-03，Asia/Hong_Kong。原目录维护并发布0.1.1，README/LICENSE保持原文，安装方式仍为酒馆填写仓库链接。

## 本轮变化

1. 实际主题给所有nav设置棕色背景，工具栏没有自己的背景规则，导致自定义蓝色只覆盖控件。现连同工具栏、页签、内部弹窗标题一起做局部背景/边框/阴影保护。测试使用强制nav/header样式及实际页提取的样式副本。
2. 选择同一基准两次取消筛选，清除左右配对。换候选仍沿用基准，双选显示正文与实际设置差异；换基准则清旧配对。正文关闭后可以点候选重新打开，点击基准优先执行取消筛选。
3. 入口先让酒馆结束关闭魔法棒菜单，再打开工坊。工坊使用原生顶层dialog，避免被原生弹窗遮挡或因移动端菜单关闭过程丢失点击。320/390px触摸上下文测试了从原生modal中的魔法棒打开、预设入口反复开关及保存确认；不能将此等同已经在用户实体手机上验收。
4. 按用户指定脚本参考，实现独立的预设排序锁。总开关默认关闭，开启后在原生预设标题区显示锁按钮，记住锁定状态，首次可沿用旧脚本的锁定偏好。通过事件拦截、原生sortable禁用和鸡尾酒拖动类控制排序，保持编辑/开关/更多可用，不移除jQuery实例，不改资源数据。解锁、总开关关闭、卸载和列表重绘均恢复相应原状态；不专门接管柏宝箱。旧脚本仍启用时需由用户先停用旧脚本。
5. 按钮改为“全选”。当前筛选结果全部勾选，包括折叠组成员；再次点击取消，仍可逐项勾选。
6. 资源保存先列出变更：新增、删除、名称、正文、设置、排序、分组成员/名称/停用状态、写回与清理。分组成员变化显示加入/移出的名称，清理提示保留备份。确认前不提交；取消保留草稿；确认时检查草稿是否变化，过期预览拒绝保存，外部并发仍由原适配器校验。保存失败保留草稿。分组“采用并保存”也经过该确认。
7. 全部浏览沿实际条目顺序显示“组标题 → 成员”，默认展开，不再把组按钮堆在顶部。非连续成员在各实际边界显示同组标题，不改变执行顺序。没有分组的条目直接显示。折叠是浏览偏好，不写资源、不制造保存项；搜索或候选对比直接显示匹配成员。
