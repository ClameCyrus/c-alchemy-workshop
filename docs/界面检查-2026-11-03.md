# 2026-11-03 原生列表和交互复查

本轮在`E:\STscript\c-alchemy-workshop`直接维护0.1.0；没有安装、覆盖或刷新当前酒馆，也没有推送GitHub。当前酒馆只读连接`http://127.0.0.1:8600/`，酒馆助手“允许监听”保持关闭，保留现有草稿。

## 原因与修正

1. 原生组折叠原来调用整份资源保存，包含克隆正文、第三方写回、保存设置、重建列表与通知。现在折叠只更新组内原生行的显示类，存一份小的浏览器偏好，不读取正文、不提交资源、不发通知。组暂停使用独立元数据保存路径，失败仅恢复本次组标记，不替换正则数组或行对象。
2. 旧分组视图隐藏了原列表并重画条目、圆点开关及“未分组”块。此方案已删除：只插入组标题，不移动、不重建原行；没有成员的组不显示，未分组条目保持原顺序。非连续成员会按原有连续段显示同组标题，折叠控制该组全部成员，不改变执行顺序。
3. 柏宝箱正则使用组壳层包住原生行，工坊接管时仅暂时展开这些已知壳层并隐藏重复组头，退出恢复。柏宝箱1.1.5预设会卸载折叠组内的原生行；本轮只读核对其`mountedGroupBodies`与`groupBodyUnmountTimers`，适配器让它自己的Vue继续挂载这些行，不改`collapsed`记录，不调用第三方保存；关闭工坊分组时恢复挂载偏好。此项依赖已核对的柏宝箱视图结构，插件版本改变后需复查。
4. 原生分组颜色取酒馆tokens；自定义基础色与派生色限定在`#prw-mount`。分组总开关位于右上角“设置”，关闭不删除记录，也不改变任何条目的原启用状态；第三方原有分组功能仍由第三方管理。
5. 旧英文相似度按两个字母组合计数，普通词容易虚高。现采用词/中文字的有序三元组及频次；部分相同至少有24个连续token且覆盖短侧至少25%，相似还需足够的共同三元组和总重合度。少于12个token的非相同正文不判相似，移除仅靠同名或同ID的兜底。特征缓存限制为估计32MB/1200项，仍分批计算。
6. 实际页面只读提取“哈｜小说叙事”与三个候选正文，在临时纯函数中使用新算法复查：文中弹幕吐槽、华丽文字演出、简单文字演出均返回无匹配。没有安装新代码或更改这些条目。
7. 双选后统一大正文对比，桌面双栏、手机全屏分页，整体关闭并保留选择。差异高亮使用酒馆已有DiffMatchPatch，限制差异计算时长和输入长度；超过100000字符仍显示完整正文，不进行高亮计算。所有正文按文本输出，不执行其中HTML。
8. 切换资源同步清空基准和提示；异步读取带请求序号，旧请求不会抢回当前选择。顶部select的额外5px下边距被局部清除，工具栏和资源栏统一36px控件高度。
9. 整张卡片可拖动，起始目标为按钮/复选框等控件时不抢拖动。插入位置按clientY与卡片边界比较，避免offsetY随子节点改变；dragenter与dragover均立即标记位置，忽略仍位于卡片内部的dragleave，解决插入线闪失。结束清理位置和滚动任务。
